# archil

`archil` is an alias for [`disk`](https://www.npmjs.com/package/disk), the canonical TypeScript SDK for Archil disks and sandboxes. It re-exports everything from `disk`, so `import { Archil } from "archil"` behaves exactly like `import { Archil } from "disk"`; new projects should depend on `disk` directly. See [docs.archil.com](https://docs.archil.com) for documentation.
